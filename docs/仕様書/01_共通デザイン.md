# 01. 共通デザイン（全デッキ）

6 デッキ・1,174 頁で共通の枠と部品。位置・大きさはインチ（x, y, w, h、小数 2 桁）、色は 16 進、文字は pt。各章の type 仕様はこの部品を組み合わせて書いている。

## 1. 用紙・フォント・作り
- 16.67 × 9.375 in（15,240,000 × 8,572,500 EMU、16:9）。全頁レイアウト「Blank」、非表示頁なし。
- フォント **Meiryo**（latin・ea・cs とも）。
- 画像はロゴ 1 点だけ（`assets/caqnal_logo.png` として保存する。サンプルから取り出せる）。それ以外の図・図解・決定木はすべて図形・ネイティブ表・ネイティブグラフ。
- 図形に影なし（`p:style` を付けない）。四角形は塗りだけで輪郭線なし。
- 文字枠: 内側の余白 0、上下中央揃え、自動縮小なし、折り返しあり。行間・段落間隔は指定なし。

## 4. 表（a:tbl）
- **テーブルスタイルなし・罫線の指定なし**（`tblPr` 空）。※ python-pptx は既定で表スタイルを付けるので外す。罫線の扱いは CAQNAL 確認（確認事項 D-7）。
- 見出し行: 塗り `173650`、文字 白 `FFFFFF` 太字。1 列目は左、2 列目以降は中央。
- 本体: 文字 `30383E` 太字なし。1 列目と文章の列は左、数値列は中央。
- 縞: 本体 1 行目から `FFFFFF` と `F3F4F5` を交互（頁ごとに白から始め直す）。
- 見出しの pt は本体より 0.75pt 小さい（例: 本体 17.25／見出し 16.5、本体 15／見出し 14.25）。
- セル余白: 左右 0.125in。上下は本編 0.083in、付録の詳細表 0.02in。上下中央揃え。
- 色で上書きするセル:
  - 点数帯: < 60.0 `F3EAD8`（淡金）、≥ 70.0 `E4EDF2`（淡青）、それ以外 `FFFFFF`（縞に関係なく白）。どの表で使うかは `06` §3。
  - 強調行（最も低い指標・自所属・合計）: 塗り `F7F4EB`＋行全体を太字（点数帯の色があるセルは色を優先し太字だけ）。
- 正負で文字色を変える・太字にする装飾は無い。

## 8. 数値と記号の書式
サンプル内で揺れているものは、CAQNAL の回答が来るまで「仮決め」に揃える（確認事項 D 章）。
| 対象 | 書式 | 仮決め（揺れの解消） |
|---|---|---|
| 点数 | 小数 1 桁 | — |
| 率 | 小数 1 桁＋% | 半角 % に統一（本文の全角 ％ をやめる） |
| r・β・R²・MAE | r・β・R² は小数 3 桁、MAE は小数 1 桁 | — |
| 差（pt） | 符号付き小数 1 桁（`+1.4`／`−1.6`）。丸める前の値どうしで差を取ってから丸める | 0 は `0.0`（`-0.0`・`+0.0` にしない） |
| 負の記号 | 表・本文は U+2212「−」 | 付録 A2・人事 A7 の半角「-」も「−」に統一。グラフの数値書式は Excel の書式のまま |
| 人数 | 3 桁区切り `1,350` | 区切りなし（「1350」「対象1397名」）も区切りありに統一 |
| 記号 | 全角「＝」「～」「／」。目次の頁範囲は en dash「–」、区間は `{下限}～{上限}` | — |
| 回答範囲 | 「回答1」「回答1・2」「回答3～5」 | — |

## 9. ノート（全頁）
- 1 行目（全頁同じ）: `出典：{回答ファイル}、{対象リスト}、{設問票}。対象リストのIDと対象外を職員コードで照合。回答データを1～5に変換し、照合済みの有効回答{n}件を集計。{案件ごとの確認事項}。デザイン参考：既存CAQNAL報告書。`
- 2 行目: 章のラベル（表紙／前付／第1章〜／資料／巻末資料／A1〜A7 など）。
- 3 行目以降: 頁の種類ごとの補足（回答状況の定義、解釈上の注意 1 文、追加分析の条件と手法の一次資料、方針資料の出典）。
- 仮決め: 分析条件は JSON のまま入れず文章で書く。作成者 PC のローカルパスは入れない（資料名と頁だけ）。章ラベルは頁の章番号と一致させる（確認事項 D-9）。
