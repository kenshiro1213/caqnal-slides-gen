# CAQNAL への確認事項（佐賀市サンプルから仕様を起こす際に、スライドだけでは決められなかったこと）

作成 2026-10-13。佐賀市のサンプル PPTX 6 点（全 1,174 頁）を正として仕様（`docs/仕様書/`）を起こした。その中で**スライドを見ても決められなかったこと**だけを挙げる。スライドから読み取れたことは仕様に書き、ここには入れていない。

- 頁の書き方: 本＝全庁本編、付＝全庁詳細付録（通し頁）、部＝部局長向け（総務部長）、課＝課長向け（人事課長）、人＝人事担当向け。
- 「仮決め」は、回答が来るまで実装で使う既定。回答が来たら設定や規則を差し替える。
- 優先度: ★＝多くの頁・全自治体に効く／数値の正しさに関わる。
