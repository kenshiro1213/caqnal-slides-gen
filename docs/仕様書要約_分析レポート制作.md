## 0. 位置づけ
- 委託範囲: データ確認・前処理 → 集計 → 統計分析 → 自由記述分析 → 強み/課題/重点組織の候補抽出 → レポート初稿 → QA
- 最終解釈・重点課題確定・施策選択・最終メッセージは CAQNAL。委託先の示唆は「初期仮説・候補」
- 設計思想: リンクアンドモチベーション型「詳細・網羅の組織別集計」＋コーン・フェリー型「結果→類型化→Key Driver→総括→打ち手」

## 1. 入力データ
必須: 当年回答 / 設問マスタ（ID・文・大中分類・結果指標orドライバー・逆転フラグ）/ 組織マスタ / 属性マスタ / 前年度回答 / 過年度設問対応表 / 非表示ルール / 自治体固有情報
- 1行=1回答者、匿名ID。「わからない/該当なし」は欠損と区別し分母から除外。逆転項目は分析スコアのみ反転
- 開始前チェック(1-3): 回答件数整合 / 設問マスタ⇄回答列 1:1 / 尺度定義あり / 組織コード紐付け / 経年対応（比較可・参考比較・比較不可）/ 匿名性設定

## 2. 前処理・匿名性
| ケース | 処理 |
|---|---|
| 未回答 | 当該設問のみ欠損 |
| わからない/該当なし | 平均・肯定率・相関・回帰の分母から除外 |
| 逆転項目 | 分析用スコアのみ反転 |
| 極端な欠損 | 結果指標の構成設問の過半が欠損 → 指標算出しない |
| 重複回答 | CAQNAL確認後に確定 |
- 標準: 組織・属性の n<5 は非表示。自由記述は件数<5 で非表示。案件指定優先
- 二次秘匿（上位から逆算可能）は要協議。AI外部送信は PII 除去済みデータのみ
- 経年区分: 比較可（同一）/ 参考比較（軽微文言変更・尺度変換）/ 比較不可（意味変更）/ 尺度変更時は 0-100 標準化を併記

## 3. 指標定義
- Mean = 有効回答合計 / 有効回答数
- Positive% = 肯定数 / 有効数 ×100（5段階は原則 4・5 が肯定。案件設計優先）、Negative%、Neutral%
- SD、Normalized = (mean−min)/(max−min)×100
- 総合エンゲージメント: 案件ごとの設問マスタで明示。CAQNAL標準は 職員満足度・ワークエンゲージメント・組織コミットメント
- 強み/課題の判定軸: 絶対水準 / 全庁差（部局−全庁）/ 前年差 / 影響度（相関・回帰）/ ばらつき（SD）

## 4. 分析仕様
- 4-1 基本: 総合指標・結果指標・カテゴリ・全設問 × 全庁/部局/課/属性 で mean・pos%・neg%・n。全庁差・前年差ヒートマップ。非表示ルール適用
- 4-2 ランキング: 高評価TOP10 / 低評価BOTTOM10 / 改善TOP10 / 悪化BOTTOM10 / 全庁比±TOP5〜10
- 4-3 有意差: 平均=Welch t、比率=比率差検定。p値のみで判定せず効果量・差分・n併記。「有意差なし＝差なし」と断定しない
- 4-4 Key Driver: 目的=総合エンゲージメント（or 結果指標）、説明=ドライバー設問、除外=結果指標・自由記述・ID・組織。手順: 相関(Pearson/Spearman) → 多重共線性(VIF) → 標準化重回帰 → 適合度確認 → 相関・β・現状スコアで順位付け → n十分な部局で部局別KD
  - ゾーン: A 最優先改善（影響高×スコア低）/ B 重要な強み（高×高）/ C 二次課題（低〜中×低）/ D 維持領域（低〜中×高）
  - 表現: 「原因」禁止 →「関連が強く改善優先度が高い要因候補」。「施策すればスコア上昇」禁止
- 4-5 4類型（エンゲージメント × 職場環境・支援、しきい値=全庁平均or中央値、経年比較は固定推奨）
  | | 環境高 | 環境低 |
  |---|---|---|
  | Eng高 | 活躍実感型 | 意欲先行型 |
  | Eng低 | 環境充足型 | 要支援型 |
  出力: 全庁構成比・前年差・部局別構成比・特徴部局（全庁比±pt）・類型別ドライバー差
- 4-6 組織ポジショニング: 2軸散布図（総合Eng×職場環境・支援 or 働きがい×働きやすさ）、バブル=n、全ラベル判読、しきい値線、前年矢印は任意
- 4-7 属性: 年代 / 職位 / 勤続 / 職種 / 任用区分
- 4-8 自由記述: マスキング → 重複・空欄除外 → テーマ分類（業務量・人員配置・上司・組織風土・評価・キャリア・職場環境・システム等）/ トーン / 要望タイプ / 組織別頻度 / 代表コメント / 定量接続。禁止: 少数からの一般化、原因補完、攻撃的原文掲載、件数と構成比の混同
- 4-9 課題統合: 6観点（低スコア / 悪化 / 組織偏在 / Key Driver / 自由記述 / ばらつき）のうち **3つ以上** → 重点課題候補

## 7. AI 示唆生成
- 計算・抽出・ランキングは決定的処理で確定。AI は文章化のみ
- 7-1 入力JSON: scope / n / overall_score / yoy_diff / org_diff / top_strengths（設問ID+値+差分）/ top_issues / key_drivers（設問ID+相関+β+スコア）/ segment_mix / comment_themes（テーマ+件数+構成比）/ evidence_flags
- 7-2 文章構造: ①事実 ②特徴 ③要因候補 ④示唆 ⑤アクション方向性
- 7-3 ルール: 根拠必須（1点につき原則2つ以上の数値）/ 比較対象明記（「全庁平均比−0.2」）/ 因果断定禁止 / 過度な一般化禁止 / 同語反復禁止 / 「組織運営」「職員」表現 / 「検討が考えられる」表現 / 機密配慮

## 8. 可視化
- 共通: 1ページ1メッセージ。タイトル=何を示すか、リード文=何が言えるか。色の意味固定（ポジティブ系/注意系/中立グレー）。平均は小数1〜2桁、割合は整数%。n数必須。非表示は「-」または「非表示」（空欄不可）。軸範囲を組織ごとに変えない
- 推奨グラフ: 総合=KPIカード＋経年折線 / カテゴリ=横棒・ドット（基準線）/ 組織=ヒートマップ（閾値固定）/ ポジショニング=散布図 / 類型=100%積み上げ / KD=Impact×Score散布 / 自由記述=テーマ構成棒 / 施策=Impact×Ease

## 9. 自動判定 閾値（標準案、パラメータ化必須。委託先は独自変更不可）
| 判定 | 標準案 |
|---|---|
| 高評価 | 全庁上位20% または 肯定率65%以上 |
| 低評価 | 全庁下位20% または 否定率20%以上 |
| 改善 / 悪化 | 前年差 ≥ +0.10 / ≤ −0.10（5段階平均） |
| 全庁比特徴 | 全庁差 ±0.15 以上 |
| 高影響 | Key Driver 上位25% |
| ばらつき大 | SD 上位20% |
| 重点課題 | 3シグナル以上 |
- 9-1 重点部局スコア: 総合が全庁下位20% +2 / 前年差悪化 +2 / 全庁差≤−0.15 +2 / KD上位項目が低評価 +2 / 自由記述で同テーマ多い +1 / 要支援型が全庁比+10pt +1。運用例: ≥6 重点フォロー候補、3〜5 要注視、≤2 通常

## 10. 施策提案
- 「課題テーマ → 現場で確認すべき要因 → 施策の選択肢」の順。Impact（関連度・対象人数・深刻度）× Ease（コスト・権限・期間・制度改定）。短期3〜6か月 / 中期6〜18か月 / 長期18か月以上
- レベル: 全庁（人事・総務・経営層: 配置・評価制度・キャリア・働き方・システム）/ 部局（業務配分・連携・会議・育成）/ 課（1on1・役割明確化・棚卸・チーム連携・称賛FB）
- 10-2 施策ライブラリ（→ `config/action_library.yaml`）
  | テーマ | 現場確認 | 施策候補 |
  |---|---|---|
  | 業務量・人員配置 | 繁忙時期、偏在、属人化、欠員 | 業務棚卸、繁閑共有、配置見直し、標準化 |
  | 上司・マネジメント | 1on1頻度、指示の明確さ、FB | 1on1、期待役割共有、評価者研修、FB機会 |
  | キャリア・成長 | 異動希望、成長機会、将来像 | キャリア面談、庁内公募、研修、ローテーション |
  | 評価・処遇 | 評価基準、説明、納得感 | 期初説明、評価面談、評価調整、制度周知 |
  | 組織連携 | 課間壁、情報共有、会議 | 横断会議、ナレッジ共有、役割整理 |
  | 職場環境 | 設備、IT、柔軟な働き方 | システム改善、設備、テレワーク等 |

## 11. QA・検収
- 5観点: 数値再現性 / 匿名性 / 分析妥当性 / 文章根拠 / ページ体裁
- データQA: 回答者数一致・主要KPI手計算一致・前年差は比較可のみ・n<5非表示・同率順位ルール一貫・KD変数仕様通り・PII残存なし
- AI文章QA: 数値整合・根拠・因果表現・過大解釈・固有名詞・施策表現
- レイアウトQA: 文字切れ・はみ出し・凡例・色統一・組織名判読・n数・フォント過小・要素位置ずれ
- 11-4 検証表: 全庁1・部局2・課2・属性2 以上を原データ→レポート値まで追跡

## 12. フロー・禁止事項
- 本格制作前に 主要分析結果・強み課題候補・KD・重点組織候補・示唆案 を一覧化し CAQNAL 確認
- 委託先独自判断禁止: 結果指標/ドライバー設問の追加削除、匿名性閾値、経年比較可否、KD目的変数、重点課題/重点部局閾値、固有事情の推測断定、承認前の最終版扱い
