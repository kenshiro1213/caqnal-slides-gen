# A. 全庁向け本編（68 頁）— サンプルから起こした仕様

> この章は佐賀市のサンプル PPTX（`spec/自治体向け/`）を正として逆に起こした仕様。共通の枠・計算規則は `01_共通デザイン.md`・`06_計算と判定の規則.md`、CAQNAL への確認は `../CAQNAL確認事項.md`（統合版。この章末の質問番号は章内の番号で、統合版に対応表がある）。

対象: `spec/自治体向け/全庁向け/佐賀市_全庁レポート_重回帰・決定木分析版_v2.pptx`（68 頁、全頁 layout=Blank、非表示頁なし）

調べ方: 68 頁すべての画像（60dpi、LibreOffice 描画）を目で確認し、抽出した JSON（位置・塗り・文字・pt・表・グラフ・ノート）と突き合わせた。グラフ（データラベル・軸・凡例・点の色）、表のセル（揃え・太字・文字色・余白・罫線）、図形の線種は python-pptx で XML を直接調べた。数値の検算は、元データの値がある箇所（詳細付録の平均、グラフに埋め込まれた値）で行った。

表記: 位置と大きさはインチで小数 2 桁（x, y, w, h）。色は 16 進。`{…}` はデータから差し込む部分、`【解釈】` はコンサルタント（interpretation）が書く文、`【自動】` はデータと規則で作れる文、`【固定】` は全自治体で共通の定型文。

### 3.43 非表示（秘匿）の条件（全 type 共通。サンプルから読めること）
- 有効回答が 5 人未満の区分は非表示にする。**ちょうど 5 人は表示する**（事務員 5/5、級情報なし 5/5、室長（係長級）5/5）。
