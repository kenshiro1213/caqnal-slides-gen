# スライドマスター仕様: `slides-master/カクナルスライド.pptx`

Google Slides からのエクスポート（shape名 `Google Shape;NNN;pNN`）。python-pptx 1.0.2 で読み込み可。
この md でレイアウト・座標・色・フォントの参照は完結する。原本を開くのは形状確認が必要なときのみ。

## 基本
- スライドサイズ: **9144000 × 5143500 EMU = 10.00 × 5.625 in**（16:9 だが標準 13.333×7.5 ではない）
- サンプルスライド 5枚（表紙 / 目次 / 中表紙 / 本文1 / 会社情報）→ 生成時は全削除して使う
- スライドマスター 4個（計29レイアウト）。**Master 3（index 3）が日本語の実運用テンプレート**
- ノートは空。メディア 8点（ロゴ・会社写真）

## 生成時のコンテンツ領域（theme.yaml に持つ値）
- title: y=0〜0.325in（placeholder に文字を入れる）
- lead（リード文）: y=0.36〜0.76in、x=0.21〜9.76in
- content: y=0.85〜5.25in、x=0.45〜9.55in（右下ページ番号 y≥5.31 を避ける）
- footnote: y=5.28〜5.55in、x=0.45〜8.9in（ページ番号の左）

## 表紙 / 中表紙
- 表紙: CENTER_TITLE(タイトル) + SUBTITLE(自治体名・日付) + 「●● 御中」TEXT_BOX (470050,643800,3055200,369300) + アクセント線 (548700,1013100,2712000,47400) + 下部中央にロゴ PICTURE (3154125,4383169,2835752,403406)
- 中表紙: 左半分または回転した金色の色面 + CENTER_TITLE + SUBTITLE

## フォント
- fontScheme はOffice既定（Arial / ＭＳ Ｐゴシック）だがスライド実体は直接指定: **Meiryo UI**(168回) / **M PLUS 1p**(146回) / Arial(25) / Quattrocento Sans(3)
- Meiryo UI・M PLUS 1p はこの Mac に未インストール → 生成は Noto Sans JP（`assets/fonts/`）をデフォルト、`config/theme.yaml` の `font.preset: meiryo` で切替
- python-pptx で日本語フォントを効かせるには `a:latin` に加えて `a:ea typeface` を注入する必要がある（`render/pptx_helpers.py: set_run_font`）

## 生成方式
1. `Presentation('slides-master/カクナルスライド.pptx')` で開く
2. 既存5スライドを sldIdLst から削除（rel も drop）
3. `slide_masters[3].slide_layouts[<name>]` を name で取得して `add_slide`
4. TITLE / CENTER_TITLE / SUBTITLE placeholder には文字を入れる。SLIDE_NUMBER placeholder には手動でページ番号文字列を入れる（フィールド更新に依存しない）
5. 本文は `add_textbox / add_picture / add_table` で絶対配置
