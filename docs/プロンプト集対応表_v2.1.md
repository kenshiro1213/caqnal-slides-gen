# プロンプト集 v2.1 と実装の対応表

原本: `spec/プロンプト集.md`（CAQNAL 自治体共通レポート作成用プロンプト集 版2.1、2026-10-13 受領）。
手順書 v2.0（`docs/仕様書要約_自治体共通版v2.md`）と同じ内容を、工程別のプロンプト 10 本と受け渡し契約にまとめたもの。
手順書から推定して作った部分のうち、プロンプト集で書き方が具体的になった点をここで実装と突き合わせる。

状態の凡例: **済**＝実装済み／**一部**＝一部実装／**未**＝未実装／**確認待ち**＝CAQNAL・自治体の確定が要る

## プロンプト別

### 1. 全体統括
- 7 段の流れは `caqnal report`（validate→…→render）で済。verify（7 番目の検証）は **未**（P7）
- 各工程の入力・出力・未解決事項の記録: run.json に工程別の指紋・未確定・警告を記録済み

### 2. 入力照合・設問辞書・集計定義
| 要件 | 状態 |
|---|---|
| ID 正規化の規則を明示、重複は採用規則と証拠を記録（自動で最後の 1 行にしない） | 済（規則が null なら停止） |
| 対象者・対象外・照合済み・有効・未照合・無回答・重複を区別 | 済（normalize_log の段階別件数） |
| 部局直轄と課所属を区別、名称だけで同名の課を混ぜない | 済（org 辞書は ID で持つ。同じ親の下の同名は validate で停止） |
| 列→設問 ID→全文→カテゴリ→目的指標の対応表 | 済（questions テーブル） |
| 年代・勤続は基準日で計算、生年月日・入職日を残さない | 済（区分にしてから保存） |
| 役職区分を級名称から推定しない | 済（設定で定義した対応だけ使う） |
| 未知の列・値・カテゴリを放置しない | 済（未知の選択肢・所属は停止） |

## 次の対応（優先順）
1. **P7 verify**: 数値照合（public ⇄ PPT の表セル・グラフキャッシュ・埋込 Excel）、漏えい検査、全頁 PNG 化、QA 記録、release_ready
2. **自由記述**: 記述者数・実質意見数・テーマ（人が確認した分類）の公開データと、人事限定の属性別
3. **interpretation.yaml の構造**: 各示唆・施策に「観測事実（根拠キー）／背景の仮説／実施案／実施条件」を分けて持つ。人事向けは方針の出典（名称・改定日・印刷頁）と方針・観測事実の対応表
4. **付録の拡充**: 部局差、属性別、分析の全結果、分冊。人事向けの所属別支援表
5. **前回比較**: 設問・選択肢・母集団・集計定義が対応する場合だけ、対応表つきで前回差を出す
