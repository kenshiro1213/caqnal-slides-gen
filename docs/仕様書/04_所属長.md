## 0. 要点

- slide type は **32**（うち所属長向けに固有、または全庁版と大きく違う変種が 13。ほかに比較列だけ違うものが 2）。分類は §3。
- 2 デッキは **同じ骨格**で、違いは次の 3 点に集約される。
  1. 部局長版にだけ「部局内のカテゴリ比較」「部局長が判断する支援の論点」の 2 頁がある（D 16・17）。このため本編は D 38 頁、K 36 頁。
  2. 比較列: 部局長版は「部局｜全庁」、課長版は「自課｜部局｜全庁」。課長版の課別表は自課の行を強調。
  3. 職員の声: 部局長版は自部局の記述のテーマ集計、課長版は**自課が少人数のため全庁のテーマ集計に切り替え**て「全庁参考」と明記。
- 付録（A1〜A3）は 2 デッキで**中身が同一**（同じ部局 = 総務部とその全課）。違いは頁番号、A1 主要指標表で強調する行、A3 の範囲（D: 総務部、K: 人事課）だけ。
- 全庁の重回帰・決定木は**全庁モデルをそのまま掲載**し、所属では再推定しない。重回帰の頁だけ自所属の点数を併記する。決定木の頁は全庁の数値のみで、右上ラベルが `佐賀市｜全庁分析（参考）｜{読者}向け` に変わる。
- 確認が必要な事項は §10 に 24 件。

## 6. 付録の構成

### 6.1 範囲の決め方
- 範囲 = **読者の所属が属する部局**（部局長版は自部局、課長版は自課の親部局）と、その部局に属する課・室等すべて。
- 両版で付録 A1・A2 の内容は同一（頁番号以外）。他部局の所属は入れない。
- 並びは組織順（所属リストの順と推定。総務部 → 総務法制課 → 秘書課 → 広報課 → 人事課 → 財政課 → 契約監理課 → 財産活用課 → 危機管理防災課 → 国際課）。自課を先頭に寄せない。

### 6.2 順序と頁数
| 区分 | 頁 | 内容 |
|---|---|---|
| A1 案内 | 1 頁 | appendix_index |
| A1 主要指標 | 1 頁 | org_indicator_table（部局の行を先頭） |
| A2 部局 | 1＋7 頁 | unit_summary＋unit_questions 1/7〜7/7 |
| A2 各課（組織順） | 1＋7 頁 ずつ | 同上 |
| A2 非表示の課 | 1 頁 | unit_suppressed |
| A3 | 属性ごとに 1〜2 頁 | response_by_attribute（範囲は自所属） |
