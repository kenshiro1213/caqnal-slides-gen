# データ形式メモ（自治体横断）

各自治体の列一覧・値分布は `local-governments/<自治体>/profile/*.md`（`caqnal profile` 出力）、設問マスタは `questions.yaml` を見る。
ここには生データを開かずに済むための「形式・落とし穴」だけをまとめる。

## 八戸市（実データあり: R7・R8）
| 項目 | R8 (`data/R8_回答.csv`) | R7 (`data/R7_回答.csv`) |
|---|---|---|
| encoding | UTF-8 with BOM (`utf-8-sig`) | 同 |
| 行×列 | 984 × 61 | 968 × 52 |
| 回答者ID / タイムスタンプ / PII列 | なし（行番号で匿名ID採番） | 同 |
| 属性列 | 列0-5 = Q1性別 / Q2役職 / Q3年代 / Q4勤続 / Q5所属部署 / Q6入庁前経験 | 同 |
| Likert列 | 列6-59（Q7〜Q60、54問） | 列6-50（Q7〜Q51、45問） |
| 自由記述 | 列60 Q61（非null 113/984、平均190字、最大1521字） | 列51 Q52 |
| 尺度 | `①そう思う / ②ややそう思う / ③どちらともいえない / ④あまりそう思わない / ⑤そう思わない` | 同 |
| 欠損 | Q56（管理職限定）のみ null=742。**一般職も約135名回答している** → 役職=管理職で絞る | なし |

### 落とし穴
- **①が最良**。丸数字を数値化すると逆スケール → `label→score` で ①→5 … ⑤→1
- 属性値も丸数字付き（`①男性`）。`③ ①②両方あり` のように丸数字の後に半角スペースが入るものがある → 先頭の丸数字1文字＋直後の空白を除去
- Q6 の「なし」コードが R7 `③` → R8 `④`（R8で「①②両方あり」が挿入）→ コードではなくラベルで突合
- カテゴリは列名の `【…】` プレフィクス（カテゴリ先頭設問のみ）。`【人事施策について】` が Q48・Q52 の2回出現。CSV `【成長実感について】` は xlsx では `現在の成長について`。**カテゴリは xlsx 設問マスタを正とする**
- R7→R8 で設問番号が41問シフト（+1〜+9）、R7 Q34「業績評価の目標設定にあたって上司との話し合い…」削除（R8 Q55 に文言変更＝参考比較）、10問追加、R7 Q36「人事評価制度をアップデート…」が処遇→人事施策へカテゴリ移動（設問文同一＝比較可）。**経年キーは設問文**
- 逆転候補: Q43「業務量が周囲より多いと感じる」、Q52「人事評価制度をアップデートする必要がある」（CAQNAL確認事項）
- 組織は部局18のみ（課なし）。監査委員事務局 n=2 → 匿名性抑制の対象
- 対象者数不明 → 回答率は算出不可（client.yaml `target_count: null`）

### 設問マスタ xlsx（`data/R8_設問_v1.2_260623.xlsx`）
- シート `R8年度設問` / `R7年度設問`。データは B〜F列、ヘッダー行4。G列以降の `e` はゴミ
- 列: B 働きがい・働きやすさ（働きがい/働きやすさ/その他）/ C カテゴリ / D #（float）/ E 設問 / F 回答
- `#` ⇄ CSV `Q{n}.` が1対1。**設問文は CSV と微妙に違う**（xlsx は短縮版）→ 結合は番号キー、`text` は CSV 由来を正とする
- R7シート `#4` 勤続年数の選択肢に誤植（`3年以上10年未満` が2回）。実CSVは正しい
- xlsx の Q6 選択肢は3択のまま（実データは4択）

## 佐賀市（設問のみ、実データ未着）
- `data/R8_設問_260805.xlsx` Sheet1、ヘッダー行3、列: No.(設問バンクID 001,004…飛び番) / 働きがい・働きやすさ / 評価カテゴリ（大） / 項目種類 / 調査設問（通し番号1〜62） / 設問 / 質問意図 / 回答
- 尺度は**正順**: `5：非常にそう思う … 1：全くそう思わない`（八戸市と逆）
- 通し番号1は「ＩＤ入力設問」＝回答者IDあり
- 軸: 働きがい / 働きやすさ / エンゲージメント（総合 #59-62）。カテゴリ（大）: 経営戦略・理念 / 経営基盤 / 事業・社会的意義 / 働き方 / 評価・処遇 / 組織風土 / キャリア形成 / コンプライアンス遵守 / その他
- 設問は「佐賀市として〜／上司が〜／職場において〜」の3視点構造
- 欠陥: #34（No.044）の軸・カテゴリ空欄、#55（No.068）の設問文欄に質問意図が入っている
- `data/R8_対象者リスト_PII.csv`: 日本語列が `?` に化けているがメール・職員番号・生年月日は生きている PII。**読まない**。実データ 1,360 行（Excel由来の空行が約100万行）

- 十和田市: シート `R8年エンゲージメント調査 (9.7修正案)` が最新（「あなたは」削除版）。追加1〜11（文字列ID、大分類: 組織風土/人事施策/WLB/研修/メンター）。追加4 は選好尺度（プライベート中心〜仕事中心）で Likert ではない。尺度ラベルに `あまりそう思わない` が2回出現する誤記
