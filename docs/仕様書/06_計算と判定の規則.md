# 06. 計算と判定の規則（データから決まるもの）

サンプルの値で検算して確かめた規則と、サンプルから読み取った件数・閾値・分割の規則をまとめる。「推定」と書いたものは CAQNAL 確認待ち（`../CAQNAL確認事項.md`）で、回答が来るまでは表の値を既定とする。

## 1. 集計
| 項目 | 規則 | 確認 |
|---|---|---|
| 点数 | (平均 − 尺度の最小) ÷ (最大 − 最小) × 100。5 段階なら (平均 − 1) × 25。**丸める前の平均から計算** | 付録 4,880 行で一致。散布図の値 56.574 ＝ 平均 3.26296 |
| 肯定・中立・否定 | 5 段階は 4・5／3／1・2 の割合。合計 100.0±0.1 | 全行 |
| 設問の n | その設問の有効回答（欠損を除く） | |
| カテゴリの点数と n | 構成設問の**すべてに回答した**職員の平均 | 全庁 評価・処遇 n＝1,349 |
| 回答率 | 照合済みの有効回答者 ÷ 対象者（対象＝ID 一覧 − 対象外）。小数 1 桁 | 1,350 ÷ 1,397 ＝ 96.6% |
| 回答者 | 対象者 ID に照合でき、定量設問に 1 問以上の有効回答がある職員 | 本編ノート |
| 属性別の回答率 | 分母はその区分の対象者 | |
| 所属の値 | 部局は部局直轄を含む部局全体。課は所属リストの課区分 | |
| 差（全庁差・部局差） | **丸める前の点数どうしの差**を小数 1 桁に丸める。部局差＝課 − 親部局、全庁差＝所属 − 全庁。全庁行は「—」、部局行の部局差は「—」 | 付録 全庁差 4,819 件・部局差 3,294 件 |
| 年代・勤続 | 基準日（佐賀市は 2026-04-01）時点の満年齢・採用日からの年数で区分 | |
| 目的指標の総合点 | 作らない（単純平均の総合点を設けない。共通 9 問が未実施なら総合・3 要素も作らない） | 本編 p7 |

## 2. 秘匿（非表示）
| 項目 | 規則 |
|---|---|
| 一次 | 有効回答 **5 名未満**の所属・区分は非表示（**ちょうど 5 名は表示**） |
| 二次（補完） | 部局から表示中の課を差し引くと少人数が推測できる場合、課も非表示（理由文「部局との差し引きによる少人数の推測を防ぐため」）。属性でも同様（例: 勤続「区分情報なし」を守るため「5～9年」も非表示）。**どれを隠すかの選び方は確認待ち**（仮決め: 表示中で人数の最も少ないものから、残りが 0 または 5 以上になるまで） |
| 表示のしかた | 所属・区分ごとまとめて隠す（対象人数・有効回答・回答率・点数のすべてを「非表示」）。付録では非表示の所属に 1 頁（`unit_suppressed`）を割き、索引・主要指標表からは消さない |
| セル単位 | 注記上は「少人数の項目は個別にも非表示」だが、サンプルに例がない。仮決め: セルの n が 5 未満なら「非表示」 |
| 部局表 | 7 名の組織も点数を表示（5 名以上なら表示） |
| 自由記述 | テーマの言及が 5 名未満は件数を出さない（所属長・人事 A6）。原文は載せない |
| 人事 A6 | 区分全体が少ないとき（例 29 歳以下 10 名）はテーマ頻度も控える |

## 3. 色と強調
| 対象 | 規則 | 使う表 |
|---|---|---|
| 点数帯 | < 60.0 `F3EAD8`、≥ 70.0 `E4EDF2`、それ以外は白（60.0 は白、70.0 は青）。判定は丸めた表示値か丸める前か確認待ち（仮決め: 丸める前） | 本編・付録 A1 の部局表（指標・カテゴリ）、KD カテゴリ表（本編 p22 の点数列）、付録 A2 のカテゴリ点数、A4 の表、所属長の課別表・カテゴリ比較・属性表 |
| 色を付けない表 | 付録 A2 の 4 指標表・設問詳細、A3、A5、KD 設問表 | |
| 最も低い指標 | 4 指標表で点数が最も低い行を `F7F4EB`＋太字。指標分布の点数欄で最も低い値だけ金 | サマリー・指標分布 |
| 自所属の行 | `F7F4EB`＋太字（課長版の課別表・付録 A1） | 所属長 |
| グラフの金 | データで決まるもの: 設問の下位 3 問（強み・課題）、カテゴリの最も低い 2 つ（推定）、重回帰の β 最大。interpretation で決めるもの: テーマ頁・論点頁・施策頁の主な設問（指定順の 1 番目）、職員の声の強調テーマ、点数と関連の頁の主な設問 | |

## 4. 件数・選び方
| 頁 | 規則 |
|---|---|
| 設問の強み・課題 | 点数の上位 3 問（高い順）と下位 3 問（低い順） |
| カテゴリ別の状態 | カテゴリを**設定の順**で並べる（点数順にしない） |
| KD 設問別 | 目的指標ごとに r の上位 5 問（表）。散布図は全説明設問 |
| KD 指標間の表 | 指標ごとに r の上位 3 問（人事は上位 2）。本編は上司満足を除いて 9 行（理由は確認待ち） |
| 重回帰・カテゴリ | 全カテゴリを β の大きい順。区間が 0 を含まない上位を帯の文で挙げる |
| 重回帰・設問 | 正の係数の上位 7 問 |
| 決定木 | 深さ 2、最小葉 100 名（佐賀市）。完全回答者で推定。本編・人事は 2 指標（満足・上司満足）、付録は全指標 |
| 検証 | 部局単位で分割（佐賀市 5 分割）した未学習部局での R²・MAE を、平均だけの予測と比べる。根元の項目の部局単位再抽出頻度 |
| 区間 | HC3 の 95% 区間（正規近似）。感度として部局単位のクラスタ頑健区間 |
| 自由記述 | テーマは固定の順（人数順にしない）。分母は記述者数（意見なし等を含む）。複数テーマ分類 |
| 人事 A7 の扱い | 課の回答 15 名以上「確認」、5〜14 名「参考」、それ未満と差し引き推測は「非表示」。全庁差は −5.0 以下のときだけ書く（推定）。注視カテゴリは最も低いカテゴリ（例外 1 件あり、確認待ち）。初動の文はカテゴリから固定文で決まる |
| 人事 工数 | 人時 ＝ 人数 × 回数 × 時間。準備・集約は固定値（佐賀市 4.0・6.0 時間）。合計の検算は一致 |

## 5. 並び順
- 指標・カテゴリ・設問: 設定の順。
- 組織: 対象リストの組織順（市長部局の部 → 支所 → 病院 → 出納室 → 行政委員会事務局 → 教育部）。部局の下に課。課は組織辞書の順。
- 属性の区分: 設定の順（巻末の属性表は対象リストの区分の順。確認待ち）。

## 6. 頁の分割
| 頁 | 1 頁の上限 | 割り振り |
|---|---|---|
| 本編の部局表（指標・カテゴリ） | 9 行 | 前から詰める（25 → 9/9/7） |
| 巻末・付録の属性別回答状況 | 10 行 | 補職 47 → 10/10/10/10/7、職名 21 → 7/7/7。仮決め: 前から詰め、最終頁が 4 行未満になるときは均等に割る |
| 付録 A1 索引・主要指標 | 12 所属 | 前から詰める |
| 付録 A2 設問詳細 | 9 問 | 前から詰める（61 → 9×6＋7）。カテゴリの境目では切らない |
| 付録 A3 設問別相関・A5 設問別重回帰 | 9 問 | 前から詰める（57 → 9×6＋3） |
| 所属長 付録 A3 属性表 | 8 行 | 前から詰める |
| 用語集 | 8 語（2 列 × 4） | 本編 3 頁、人事 2 頁 |
| 詳細付録の冊 | 350 頁 | 350 頁で機械的に切る（所属の途中でも切る。下冊に表紙なし）。確認待ち |
| 所属長 付録 A1 | 10 行 | 1 頁（超える場合は確認待ち） |
タイトルの末尾に ` k/n`（1 頁でも属性表は `1/1` を付ける）。

## 7. 読者の範囲
| 読者 | 本編の範囲 | 付録の範囲 |
|---|---|---|
| 全庁 | 全庁（部局は表で全部局） | 全所属 |
| 部局長 | 自部局（部局直轄を含む）と、その課の比較 | 自部局とその課（A1・A2）、自部局の属性（A3） |
| 課長 | 自課、親部局・全庁との比較、同じ部局の課の比較 | 親部局とその全課（A1・A2。確認待ち）、自課の属性（A3） |
| 人事 | 全庁 | 部局の集約（A1）、全庁（A2）、課室等は A7 の支援表だけ |
| 自所属の職員の声 | 所属の記述が少ないときは全庁の集計に切り替え「全庁参考の記述者 {N}名」と書く（閾値は確認待ち） | |
| 全庁の重回帰・決定木 | 所属長版では所属で再推定せず全庁モデルを「参考」として載せる | |
